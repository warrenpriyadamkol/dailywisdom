DAILY WISDOM — YEAR-ROUND STARTER EDITION

Includes 365 dated daily applications based on THREE scripture-based teaching clusters. The quotations recur. This is NOT 365 independently sourced religious lessons.

To install on iPhone: upload the four web files to an HTTPS static hosting service (e.g. GitHub Pages, Netlify), open the hosted URL in Safari, tap Share > Add to Home Screen. Opening index.html directly from Files is not equivalent to installing the app and may restrict storage.

Saved reflections and journal notes remain on each device in browser local storage. There is no cloud sync or account. For sharing with friends, host over HTTPS.

Source and translation review is recommended before wider publication.
